# NotebookLM לגיליון — השגרה השבועית

ל-NotebookLM הרגיל אין עדיין API, אז הפעולה ידנית — כ-5 דקות בשבוע. התוצאה: כפתור **"שאלו את NotebookLM"** (כל קורא יכול לשאול שאלות על כל הכתבות של השבוע) וכפתור **"🎧 האזינו לגיליון"** (פודקאסט של NotebookLM על הגיליון) בפתיח.

הכל דרך שלוש פקודות בטרמינל, בתיקיית הפרויקט.

---

## 1. רשימת המקורות (30 שניות)

```bash
node scripts/notebook.mjs sources 2026-09-06
```

(במקום `2026-09-06` — תאריך הגיליון, כמו שם הקובץ ב-`content/digests/`.)

זה מדפיס את כל הקישורים של הגיליון, שורה לכל אחד. **העתיקי את כל השורות שמתחת לקו.**

## 2. יצירת המחברת (2 דקות)

1. **https://notebooklm.google.com** → **New notebook**
2. שם למחברת: `רדאר AI · גיליון 3`
3. **Add source → Website** → הדביקי את כל הקישורים (NotebookLM מקבל כמה שורות בבת אחת) → **Insert**
4. חכי שהמקורות ייטענו. מקור שנכשל (חומת תשלום) — פשוט תמחקי, זה בסדר.

## 3. שיתוף המחברת (30 שניות)

1. למעלה: **Share** → תחת **General access** בחרי **Anyone with the link**
2. ודאי שההרשאה היא **Viewer** (הם יכולים לשאול שאלות, לא לערוך)
3. **Copy link**

חזרה לטרמינל:

```bash
node scripts/notebook.mjs link 2026-09-06 https://notebooklm.google.com/notebook/XXXX
```

## 4. הפודקאסט (2 דקות + זמן ייצור)

1. במחברת, בצד: **Audio Overview → Customize** (אופציונלי — אפשר לכתוב "התמקדו במה זה אומר לסוכנות חלל ממשלתית") → **Generate**
2. הייצור לוקח כמה דקות. כשמוכן: **⋯ → Download**. יורד קובץ `.wav` גדול (בדרך כלל 50–150MB) — זה בסדר, הסקריפט מכווץ אותו.

```bash
node scripts/notebook.mjs audio 2026-09-06 "C:\Users\yalig\Downloads\Audio Overview.wav"
```

זה ממיר ל-mp3 של ~5–10MB ומעתיק לפרויקט.

## 5. פרסום (30 שניות)

```bash
git add -A && git commit -m "גיליון 3 — NotebookLM ופודקאסט" && git push origin clean-main:main
```

תוך כדקה שני הכפתורים באוויר.

## שאלות

**חייבים גם וגם?** לא. אפשר רק קישור (שלבים 1–3 + 5), או רק פודקאסט. כל כפתור מופיע רק אם המידע שלו קיים.

**מה הקוראים רואים כשלוחצים "שאלו את NotebookLM"?** את המחברת נפתחת ב-NotebookLM שלהם, עם כל המקורות טעונים, ותיבת צ'אט. הם צריכים חשבון גוגל.

**אפשר בעברית?** כן. ב-Audio Overview אפשר לבחור שפת פלט (הגדרות → Output language → עברית). האיכות טובה, המבטא קצת אמריקאי.

**מתי זה יהיה אוטומטי?** ברגע שגוגל ישחררו API צרכני ל-NotebookLM (הם הצהירו שהוא בעבודה). הצינור מוכן — רק שלב 2–4 יוחלף בסקריפט.
